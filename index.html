🌳 TreeBot Explorer v3

Junior tree census · mobile field test · AI-assisted

1. Observe a tree

Location not captured
GPS requires HTTPS or localhost and location permission. Coordinates can be approximate.

2. Capture evidence

Clear, close-up leaf and fruit photos usually help more than distant video. Do not damage the tree.

Video frames are extracted locally. Original videos are not uploaded or saved by this app.

3. Identify with AI

Optional online feature: obtain your own Pl@ntNet API key. Images sent for identification go to Pl@ntNet. Do not include people or private details in photos. Never treat AI identification as certain.

4. My tree registry 0 trees

5. Review queue and audit trail

Students submit observations; a teacher or expert reviews them. Reviewer identity is self-declared, not authenticated. A reviewed record can be reopened for corrections.

6. Sync and backups

Local IndexedDB is the primary store. Cloud sync is manual, not automatic. Cloud copies include names, coordinates, notes and thumbnails. Use a private repository for sensitive locations. Do not store secrets in tree records.

GitHub repository backup

Token is not saved by TreeBot. Upload writes data/treebot-records.json. Public repositories expose this data to everyone. Prefer private repos for real fieldwork.

Google Drive backup

Requires your own Google Cloud OAuth web client with this HTTPS origin authorized, Google Drive API enabled, and the drive.file scope. Connect via Google sign-in; no Google password is collected. Backup is stored as TreeBot-records.json in your Drive.

Portable backup

Install and learn

On Android Chrome, open the hosted HTTPS site, then use browser menu → Add to Home screen. Camera, GPS, and AI require permissions and network access as applicable. Saved tree metadata and compressed thumbnails stay in your browser's IndexedDB. This single-file test is not a full offline-installable PWA.
